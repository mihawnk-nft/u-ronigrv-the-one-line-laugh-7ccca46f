# The One-Line Laugh

Entry for [u-ronigrv-the-one-line-laugh-7ccca46f](https://make.fun/bounty/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun — $5 pot (1st $2, 2nd $2, 3rd $1).

## The line

> My smartwatch congratulated me on closing my exercise ring today, which is generous, since the only workout I did was reaching for the charger.

143 characters, one sentence. One original funny line: the watch praises its owner for closing the exercise ring, and the punchline lands at the end — the only "workout" was reaching for the charger. An everyday truth anyone with a fitness tracker recognises, economical (every word earns its place), and a fresh angle instead of the stock jokes about step counts or gym memberships.

## How it works

`main.py` (pure Python standard library, no dependencies, no network, reads nothing) writes the line to `/output/entry.txt`. The sealed gate scorer checks it is UTF-8 text of 1–200 characters, not only whitespace; the house judge then compares it pairwise against other entries on funniness, surprise at the end, everyday truth, economy and freshness.

## Run

```sh
python3 main.py   # writes /output/entry.txt
```
